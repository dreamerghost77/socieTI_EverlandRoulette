# 에버랜드 어드벤처 패스

놀이기구와 티켓 주인을 차례로 뽑아 16명을 4명씩 4팀으로 배정하는 가챠입니다. 미션 칸은 비어 있으며, 미션 추첨은 아직 구현하지 않았습니다.

## 추첨 순서

1. 빈 티켓을 발권하고 **놀이기구 뽑기**를 누릅니다.
2. 원통이 회전하는 동안 화면이 서서히 사라집니다. 빛, 테마별 움직임, 부분 실루엣을 거쳐 마지막에 놀이기구가 공개됩니다.
3. **티켓 주인 뽑기**를 누르면 A–Z 알파벳 원통 두 개가 각각 회전해 이름 이니셜을 정합니다. 첫 번째와 두 번째 원통은 시간차를 두고 멈춥니다.
4. 같은 이름 이니셜을 가진 참가자가 둘 남아 있으면, 뒷면이 보이는 성씨 카드 두 장 중 하나를 직접 고릅니다. 선택한 카드가 뒤집히며 성씨와 최종 참가자를 공개합니다.
5. 참가자의 이니셜과 놀이기구가 티켓에 기록됩니다. **다음 티켓 뽑기**로 다음 배정을 진행합니다.

### 참가자

`KMK`, `MJ`, `MH`, `BJ`, `SB`, `MYJ`, `PMK`, `SI`, `JT`, `KW`, `SH`, `JW`, `HW`, `SW`, `CYJ`, `SM`

두 글자는 이름 이니셜, 세 글자는 성씨 이니셜 + 이름 이니셜입니다.

| 이름 룰렛 결과 | 성씨 카드 | 최종 참가자 |
| --- | --- | --- |
| MK | K / P | KMK / PMK |
| YJ | M / C | MYJ / CYJ |

그 외 이름 이니셜은 바로 참가자를 확정합니다. 같은 이름 이니셜의 두 사람 중 한 명이 이미 배정된 경우에는 남은 한 명으로 자동 확정합니다. 성씨 카드는 매번 섞고 선택 전에는 알파벳을 공개하지 않습니다. 연출 건너뛰기는 원통 회전을 끝내지만 카드를 대신 선택하지 않습니다.

### 팀과 공정한 추첨

| 놀이기구 팀 | 정원 | 결과 공개 연출 |
| --- | --- | --- |
| T 익스프레스 | 4명 | 목재 레일과 급강하하는 열차, 속도선 |
| 아마존 익스프레스 | 4명 | 정글과 급류, 원형 보트와 물결 |
| 썬더폴스 | 4명 | 번개, 낙하하는 보트와 물보라 |
| 허리케인 | 4명 | 바람의 소용돌이와 회전하는 팔 |

각 팀의 남은 좌석 수에 비례해 놀이기구를 추첨하므로 처음 확률은 각각 25%이고, 4명이 채워진 팀은 제외됩니다. 이름은 아직 배정되지 않은 참가자 중 같은 확률로 추첨합니다. `MK`, `YJ`는 두 명이 남아 있으면 이름 그룹에 두 명분의 확률을 주고, 카드 선택으로 성씨를 정합니다. 확정 전 홈으로 돌아가면 참가자와 좌석을 소모하지 않습니다. 총 16장의 티켓을 확정하면 팀별 4명으로 끝납니다.

## 배정 현황과 저장

메인 화면의 **참가자 배정 현황**에서 팀별 명단과 남은 참가자를 확인할 수 있습니다. 확정한 배정은 `localStorage`에 저장하여 같은 브라우저에서 새로고침해도 이어집니다. 다른 기기나 브라우저와 실시간 공유되는 현황은 아니므로 행사 진행용 브라우저 하나에서 연속으로 추첨하세요. 저장소 접근이 차단된 경우에는 현재 창에서만 배정을 유지합니다.

**전체 배정 초기화**는 확인 창을 거쳐 저장된 배정과 티켓을 지웁니다. 미완성 추첨이나 카드 선택 대기는 저장하지 않습니다.

## 연출과 접근성

놀이기구 결과는 중립색 빛(0–1.2초), 색과 추상적인 움직임(1.2–2.7초), 부분 실루엣(2.7–4.8초), 완성된 형상(4.8초부터) 순서로 진행됩니다. 이름·태그·티켓 아이콘은 연출 시작 5.4초 뒤 처음 공개됩니다.

기기의 동작 줄이기 설정에서는 회전 시간을 줄이고 정적인 놀이기구 일러스트를 보여줍니다. 성씨 카드는 이 설정에서도 직접 선택합니다. 효과음은 기본적으로 꺼져 있으며 사용자가 직접 켤 수 있습니다.

CSS, SVG, Canvas, Web Audio만 사용합니다. 외부 영상이나 이미지, 런타임 라이브러리 없이 동작합니다. 연출의 참고 자료는 [REFERENCES.md](REFERENCES.md)에 기록했습니다.

## 실행

빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열 수 있습니다. 배정 저장을 일관되게 사용하려면 로컬 서버나 GitHub Pages로 여는 것을 권장합니다.

```sh
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 엽니다.

## GitHub Pages 배포

GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/(root)`를 선택합니다. 정적 파일만 사용하므로 서버나 API 키가 필요하지 않습니다.

기본 주소는 https://dreamerghost77.github.io/socieTI_EverlandRoulette/ 입니다. Pages가 활성화되어 있으면 `main`에 푸시된 변경이 배포됩니다.
