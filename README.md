# 에버랜드 어드벤처 패스

빈 티켓을 놀이기구 뽑기로 채우는 가챠 경험입니다. 발권되는 티켓을 먼저 보여주고, 뽑기를 누르면 원통형 추첨과 놀이기구별 결과 연출이 이어집니다. 결과를 확인하고 **티켓에 담기**를 누르면 첫 번째 칸에 놀이기구와 스탬프가 기록됩니다. 미션 칸은 빈 상태로 남으며, 미션 추첨은 이번 구현 범위에 포함하지 않았습니다.

## 놀이기구별 연출

8개 놀이기구는 각각 12.5%의 같은 확률로 뽑힙니다.

| 놀이기구 | 결과 공개 연출 |
| --- | --- |
| T 익스프레스 | 목재 레일과 급강하하는 열차, 속도선 |
| 아마존 익스프레스 | 정글과 급류, 원형 보트와 물결 |
| 썬더폴스 | 번개, 낙하하는 보트와 물보라 |
| 롤링 엑스트레인 | 네온 레일을 질주하는 열차 |
| 허리케인 | 바람의 소용돌이와 회전하는 팔 |
| 더블락스핀 | 두 개의 기계 회전축과 불꽃 |
| 렛츠 트위스트 | 교차 궤도를 따라 도는 캡슐 |
| 매직스윙 | 흔들리는 곤돌라와 반짝이는 별 |

결과 이름, 티켓, 버튼을 시간차로 공개하며 **연출 건너뛰기**도 지원합니다. 기기의 동작 줄이기 설정에서는 긴 회전을 줄이고 정적인 놀이기구 일러스트를 보여줍니다. 효과음은 기본적으로 꺼져 있으며 사용자가 직접 켤 수 있습니다.

CSS, SVG, Canvas, Web Audio만 사용합니다. 외부 영상이나 이미지, 런타임 라이브러리 없이 동작합니다. 연출의 참고 자료와 영상 접근 제약은 [REFERENCES.md](REFERENCES.md)에 기록했습니다.

## 실행

빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 로컬 서버가 필요하면 저장소 루트에서 다음 명령을 실행하세요.

```sh
python3 -m http.server 8000
```

그다음 http://localhost:8000 을 열면 됩니다.

## GitHub Pages 배포

GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/(root)`를 선택하면 프로젝트 사이트로 공개할 수 있습니다. 정적 파일만 사용하므로 서버나 API 키가 필요하지 않습니다.

기본 주소는 https://dreamerghost77.github.io/socieTI_EverlandRoulette/ 입니다. Pages가 활성화되어 있으면 `main`에 푸시된 변경이 배포됩니다.
